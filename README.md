**Costa Verde** — an original 2D top-down open-world crime game built for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Marco Solis just got out, and Mama Rosa has five jobs for him across a sun-soaked invented city: steal a coupe in Old Town, pick up a package downtown, make a 90-second delivery to Portside, lose the heat, and rob Costa Verde Trust before escaping in the orange getaway car. The city lives around you — traffic, pedestrians, police who answer your wanted level, car theft, combat, pickups, a HUD with a live minimap, and a save that remembers your progress.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests: the game is static files under `game/`, and every sound is synthesised with the Web Audio API.

WASD moves and drives · E steals and enters cars · SPACE punches · Click shoots · P pauses · M mutes. Screenshots are deterministic: `?shot=start|play|chase|mission&seed=1`.
